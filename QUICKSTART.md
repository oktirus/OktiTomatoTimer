# 🚀 Швидкий старт TomatoTimer

## Крок 1: Встановлення Python

Завантажте і встановіть Python 3.8 або новіший з [python.org](https://www.python.org/downloads/)

**Важливо:** Під час встановлення поставте галочку "Add Python to PATH"!

## Крок 2: Встановлення залежностей

**✅ НЕ ПОТРІБНО НІЧОГО ВСТАНОВЛЮВАТИ!**

Програма працює зі стандартними бібліотеками Python (включно зі звуком через winsound).

~~Відкрийте командний рядок (cmd) у папці проекту і виконайте:~~

~~```bash
pip install pygame  # ❌ Не працює на Python 3.14+
```~~

**Примітка:** На Python 3.14 бібліотеки pygame та playsound не встановлюються. Програма автоматично використовує **winsound** (вбудований у Windows) - це працює чудово!

Детальніше про звук читайте в [SOUND_INFO.md](SOUND_INFO.md)

## Крок 3: Запуск програми

### Варіант 1 (Windows) - через bat файл:
Подвійний клік на файл `run.bat`

### Варіант 2 - через командний рядок:
```bash
python main.py
```

### Варіант 3 - подвійний клік на main.py
Просто подвійний клік на файл `main.py` (якщо Python правильно встановлено)

## Готово! 🎉

Програма запустилась! Натисніть кнопку **"Старт"** і почніть працювати продуктивно!

## Перше налаштування

1. Натисніть **⚙ Налаштування**
2. Встановіть зручний для вас час роботи (рекомендується 25 хвилин)
3. Встановіть час перерви (рекомендується 5 хвилин)
4. Налаштуйте гучність звуку
5. За бажанням увімкніть автозапуск при старті системи
6. Збережіть налаштування

## Як використовувати

1. **Натисніть "Старт"** - почнеться робочий час ⏱
2. **Працюйте зосереджено** - таймер відраховує час
3. **Почнеться перерва автоматично** - екран заблокується на весь екран 🔒
4. **Виконайте вправу** - програма покаже пораду для розминки 💡
5. **Відпочивайте** - можете переглянути інші поради
6. **Повернення до роботи** - після закінчення перерви таймер скидається

## Важливі моменти

- ⚠️ **Під час перерви екран блокується повністю** - це гарантує, що ви відпочинете!
- 🔑 **Натисніть Escape** під час перерви для аварійного виходу (потрібне підтвердження)
- 📊 **Статистика** показує скільки помідорів ви виконали за сеанс
- 🔊 **Звуковий сигнал** сповіщає про закінчення роботи та перерви

## Налаштування автозапуску

Щоб програма запускалась при старті Windows:

1. Відкрийте **⚙ Налаштування**
2. Увімкніть **"Запускати при старті системи"**
3. Збережіть

Готово! Тепер TomatoTimer буде запускатися автоматично при включенні ПК.

## Додавання власних порад

Відредагуйте файл `data/tips.json` та додайте свої вправи у форматі:

```json
{
  "id": 21,
  "title": "Моя вправа",
  "description": "Опис того, що потрібно зробити",
  "duration": "1 хвилина"
}
```
