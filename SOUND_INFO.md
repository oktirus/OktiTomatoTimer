# 🔊 Інформація про звук у TomatoTimer

## ✅ Коротка відповідь

**НЕ ПОТРІБНО НІЧОГО ВСТАНОВЛЮВАТИ!**

Програма працює "з коробки" на Windows, використовуючи вбудований модуль `winsound`.

---

## 📋 Детальна інформація

### Які бібліотеки підтримує TomatoTimer?

Програма автоматично визначає доступні бібліотеки в такому порядку:

1. **pygame** (найкращий, але не працює на Python 3.14)
2. **playsound** (простий, але не працює на Python 3.14)
3. **winsound** ✅ (вбудований у Python для Windows)
4. **afplay** (для macOS)
5. **beep** (для Linux)

### Що використовується зараз?

Коли ви запускаєте програму, в консолі з'являється повідомлення:

```
🔊 Звук: системний (winsound/afplay/beep)
```

Це означає, що використовується **winsound** - все працює правильно!

---

## 🎵 Підтримка звукових форматів

### winsound (те, що у вас працює):
- ✅ `.wav` файли
- ❌ `.mp3` - не підтримується
- ❌ `.ogg` - не підтримується

### Системний сигнал:
Якщо звукового файлу немає або формат не підтримується, програма відтворить **системний звук Windows** (MessageBeep).

## 🔧 Додавання власних звуків

### Варіант 1: Використовуйте .wav файли

1. Знайдіть або конвертуйте ваші звуки в формат `.wav`
2. Покладіть файли в папку `data/sounds/`
3. Відкрийте налаштування TomatoTimer
4. Виберіть ваш звук зі списку

**Де взяти .wav звуки:**
- https://freesound.org/ (безкоштовні звуки)
- https://mixkit.co/free-sound-effects/ (безкоштовні ефекти)
- Конвертуйте MP3 → WAV онлайн: https://convertio.co/mp3-wav/

### Варіант 2: Конвертація MP3 в WAV

Якщо у вас є .mp3 файли, конвертуйте їх:

**Онлайн:**
- https://convertio.co/mp3-wav/
- https://online-audio-converter.com/

**Програми:**
- Audacity (безкоштовна)
- VLC Media Player (може конвертувати)

## 🐍 Python 3.14 та несумісність бібліотек

У вас встановлено **Python 3.14** (нова версія), тому:

❌ **pygame** - не встановлюється (проблеми з компіляцією)
❌ **playsound** - не встановлюється (помилка inspect.getsource)

✅ **winsound** - працює ідеально (вбудований модуль)

### Якщо хочете pygame/playsound:

Опція 1: Використовуйте .wav файли з winsound (рекомендовано)

Опція 2: Встановіть додаткову версію Python 3.11:
```bash
# Завантажте Python 3.11 з python.org
# Створіть віртуальне середовище
python3.11 -m venv venv_311
venv_311\Scripts\activate
pip install pygame
python main.py
```

## ❓ Поширені питання

**П: Чому не встановлюється pygame?**
В: Python 3.14 дуже новий, pygame ще не адаптований. Використовуйте winsound або Python 3.11.

**П: Чи можу я використовувати MP3 файли?**
В: Ні, winsound підтримує тільки .wav. Конвертуйте MP3 в WAV.

**П: Звуки дуже тихі/гучні?**
В: Регулюйте гучність у налаштуваннях програми (0-100%). Для winsound це налаштовує системну гучність.

**П: Програма не видає звуку?**
В: Перевірте:
1. Чи увімкнено звук у налаштуваннях програми
2. Чи системна гучність Windows не на 0
3. Чи є звукові файли .wav у папці data/sounds/

**П: Хочу кращі звуки?**
В: Завантажте безкоштовні .wav звуки з freesound.org або mixkit.co
