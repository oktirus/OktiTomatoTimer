# 🍅 TomatoTimer

**TomatoTimer** - це потужний таймер продуктивності за методом Pomodoro з унікальною функцією блокування екрану під час перерв. Програма допомагає підтримувати продуктивність та здоров'я, нагадуючи про необхідність робити перерви та пропонуючи вправи для розминки.

## ✨ Основні можливості

- ⏱ **Налаштовуваний таймер Pomodoro** - встановлюйте власний час роботи та перерв
- 🔒 **Блокування екрану під час перерви** - повноекранний режим, який гарантує, що ви зробите перерву
- 💡 **100 порад для здоров'я** - вправи для спини, шиї, очей під час перерви
- 🔊 **Налаштування звуку** - регулювання гучності та вибір мелодій
- 🚀 **Автозапуск** - програма може автоматично запускатися при старті системи
- 📊 **Статистика** - кількість помідорів за сьогодні (зберігається між запусками)
- 🔔 **Іконка в треї** - прогрес у треї; хрестик згортає вікно, вийти можна через меню іконки
- 🎨 **Інтерфейс Windows 11** - Fluent Design (PySide6 + Fluent Widgets), світла й темна тема за системою

## 🎯 Унікальна функція: Блокування екрану

Коли закінчується робочий час, TomatoTimer **автоматично відкривається на весь екран** (аналогічно F11) і показує:
- Таймер зворотного відліку перерви
- Випадкову пораду для розминки
- Можливість перегорнути до іншої поради

Це забезпечує, що ви **дійсно відпочинете**, а не продовжите працювати!

## 📋 Вимоги

- Python 3.10–3.14
- PySide6, PySide6-Fluent-Widgets (інтерфейс і трей; встановлюються з `requirements.txt`)
- pygame (опціонально: гучність і MP3/OGG; без нього звук лише WAV через winsound)

## 🚀 Встановлення

### 1. Клонування репозиторію або завантаження

```bash
git clone https://github.com/yourusername/TomatoTimer.git
cd TomatoTimer
```

### 2. Встановлення залежностей

```bash
pip install -r requirements.txt
```

**Примітка:** pygame не входить у `requirements.txt`, бо його колеса є не для всіх нових версій Python. За потреби: `pip install pygame==2.6.1`.

### 3. Запуск програми

```bash
python main.py
```

## 📖 Використання

### Базове використання

1. **Запустіть програму** - подвійний клік на `main.py` або виконайте `python main.py`
2. **Натисніть "Почати"** - почнеться робочий час (за замовчуванням 25 хвилин)
3. **Працюйте** - таймер відраховує час
4. **Перерва починається автоматично** - після закінчення робочого часу екран блокується і показується порада
5. **Відпочивайте** - виконайте запропоновану вправу
6. **Перерва закінчується** - таймер повертається до очікування або одразу запускає роботу (опція "Автоматично запускати роботу після перерви")
7. **Кожна N-та перерва довга** - за замовчуванням після 4-го помідора

### Налаштування

Відкрийте сторінку **Налаштування** (іконка шестерні внизу бічної панелі). Зміни застосовуються одразу, як у налаштуваннях Windows 11.

#### Таймер
- **Робота** - від 1 до 60 хвилин (стандарт: 25)
- **Перерва** - від 1 до 30 хвилин (стандарт: 5)
- **Довга перерва** - від 5 до 60 хвилин (стандарт: 10)
- **Цикл** - скільки помідорів до довгої перерви, від 2 до 10 (стандарт: 4)
- **Автостарт роботи** - починати роботу одразу після перерви

#### Перерва
- **На весь екран** - перекриває всі монітори; інакше перерва відкривається у вікні поверх інших
- **Поради** - вправи для розминки

#### Звук
- **Звукові сигнали**, **гучність** і кнопка **Перевірити**
- **Кінець роботи / кінець перерви** - власний файл або системний звук

#### Система
- **Автозапуск** разом з Windows
- **Тема** - як у системі, світла або темна
- **Скинути налаштування** - з підтвердженням; статистика за сьогодні зберігається

### Гарячі клавіші

- **Escape** (під час перерви) - дострокове завершення перерви (потребує підтвердження)

## 💡 Поради для здоров'я

Програма включає 100 порад для розминки:
- Вправи для шиї
- Розтяжка спини
- Вправи для очей (правило 20-20-20)
- Розминка плечей
- Дихальні вправи
- І багато іншого!

Ви можете додати власні поради, відредагувавши файл `data/tips.json`.

## 🔧 Налаштування порад

Відкрийте `data/tips.json` і додайте власні поради у форматі:

```json
{
  "id": 21,
  "title": "Назва вправи",
  "description": "Детальний опис того, що потрібно зробити",
  "duration": "30 секунд"
}
```

## 🎵 Додавання власних звуків

1. Відкрийте налаштування і натисніть "Вибрати..." біля потрібного звуку
2. Без pygame підтримується лише WAV; MP3/OGG і гучність потребують pygame
3. Або змініть `work_end_sound` та `break_end_sound` у `~/.tomatotimer/settings.json` (порожньо = системний звук)

## 🖥️ Підтримка платформ

- ✅ **Windows** - повна підтримка (включно з автозапуском)
- ✅ **macOS** - підтримка (автозапуск через Launch Agents)
- ✅ **Linux** - підтримка (автозапуск через .desktop файл)

## 📦 Створення виконуваного файлу (exe)

Запустіть `build.bat` — він встановить залежності фіксованих версій і збере `dist/TomatoTimer.exe`.

Виконуваний файл буде у папці `dist/`.

## ❓ Поширені питання

### Програма не запускається?
- Переконайтеся, що встановлено Python 3.10–3.14
- Перевірте чи встановлені всі залежності: `pip install -r requirements.txt`

### Звук не працює?
- Встановіть pygame: `pip install pygame`
- Перевірте налаштування гучності в програмі
- Увімкніть звук у налаштуваннях

### Де шукати помилки?
- Лог: `~/.tomatotimer/tomatotimer.log` (у exe консолі немає)
- Пошкоджений `settings.json` переноситься в `settings.json.bak`, програма стартує з налаштуваннями за замовчуванням

### Як запустити тести?
```bash
python -m unittest
```

### Як вимкнути блокування екрану?
- Відкрийте налаштування
- Зніміть галочку "Повноекранний режим під час перерви"

### Як змінити час роботи?
- Відкрийте сторінку "Налаштування"
- Змініть "Робочий час" та "Час перерви"
- Збережіть
