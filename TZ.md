# Технічне завдання: TomatoTimer

## 1. Загальний опис проекту

**Назва проекту:** TomatoTimer
**Тип додатка:** Десктопний застосунок для Windows/macOS/Linux
**Призначення:** Таймер продуктивності за методом Pomodoro з блокуванням екрану під час перерв

## 2. Рекомендований технологічний стек

**Основна мова програмування:** Python 3.10+

**Обґрунтування вибору:**
- ✅ Кросплатформеність (Windows, macOS, Linux)
- ✅ Простота розробки GUI (Tkinter входить у стандартну бібліотеку)
- ✅ Багатий екосистема бібліотек для роботи зі звуком
- ✅ Легка інтеграція з системою автозапуску
- ✅ Швидка розробка та підтримка

**Основні бібліотеки:**
- **GUI:** `tkinter` (стандартна) або `PyQt6` (для більш сучасного інтерфейсу)
- **Звук:** `pygame.mixer` або `playsound`
- **Автозапуск:** `pywin32` (Windows), `plistlib` (macOS), власний `.desktop` файл (Linux)
- **Конфігурація:** `json` або `configparser`
- **Повноекранний режим:** вбудовані можливості `tkinter`

**Альтернативні варіанти:**
- **Electron + JavaScript:** якщо потрібен більш сучасний UI, але більший розмір
- **C# + WPF/WinForms:** для Windows-only варіанту

## 3. Функціональні вимоги

### 3.1. Основні функції таймера

#### 3.1.1. Налаштування часу
- **Робочий час (фокус):** налаштовуваний інтервал (типово 25 хвилин)
  - Діапазон: 1-60 хвилин
  - Крок зміни: 1 хвилина
  - Збереження значення між сеансами

- **Час перерви:** налаштовуваний інтервал (типово 5 хвилин)
  - Діапазон: 1-30 хвилин
  - Крок зміни: 1 хвилина
  - Збереження значення між сеансами

#### 3.1.2. Функціонал таймера
- Відображення залишку часу у форматі MM:SS
- Кнопки керування:
  - **Старт** - запуск таймера
  - **Пауза** - тимчасова зупинка
  - **Скидання** - повернення до початкового значення
- Автоматичне перемикання між робочим часом та перервою
- Візуальна індикація поточного режиму (робота/перерва)

### 3.2. Звукові налаштування

#### 3.2.1. Гучність дзвінка
- Регулятор гучності: 0-100%
- Можливість вимкнення звуку (гучність 0% або окрема кнопка mute)
- Тестування звуку перед збереженням
- Збереження налаштувань гучності

#### 3.2.2. Вибір мелодії
- Список попередньо завантажених мелодій (3-5 варіантів)
- Можливість додавання власних мелодій (.mp3, .wav)
- Попередній прослуховування мелодії перед вибором
- Різні мелодії для:
  - Закінчення робочого часу (початок перерви)
  - Закінчення перерви (початок роботи)

### 3.3. Автозапуск при старті ПК

#### 3.3.1. Налаштування автозапуску
- Опція в налаштуваннях "Запускати при старті системи"
- Автоматичне додавання/видалення з автозапуску
- Поведінка при запуску:
  - Відкриття головного вікна програми
  - Відображення кнопки "Старт"
  - Таймер у режимі очікування (не запущений)

#### 3.3.2. Реалізація по платформах
- **Windows:** додавання до реєстру або папки автозапуску
- **macOS:** створення Launch Agent
- **Linux:** створення .desktop файлу в ~/.config/autostart/

### 3.4. Блокування екрану під час перерви

#### 3.4.1. Повноекранний режим
- При закінченні робочого часу → автоматичне розгортання вікна на весь екран
- Режим аналогічний F11 (без рамок вікна, панелі завдань тощо)
- Вікно завжди поверх інших (topmost)
- Неможливість згорнути або закрити вікно стандартними методами

#### 3.4.2. Відображення під час перерви
- **Таймер зворотного відліку** перерви (великий шрифт, по центру екрана)
- **Текстова порада** для розминки спини
- **Можливість дострокового завершення перерви:**
  - Кнопка "Пропустити перерву" (опціонально, можна приховати)
  - Або гарячі клавіші (Esc + підтвердження)

#### 3.4.3. Блокування взаємодії
- Блокування доступу до інших програм до закінчення перерви
- Можливість аварійного виходу (Ctrl+Alt+Esc або інша комбінація)

### 3.5. Система порад для перерви

#### 3.5.1. База порад
- Окремий файл зі списком порад (наприклад, `tips.json` або `tips.txt`)
- Мінімум 15-20 порад для розминки спини та очей
- Формат кожної поради:
  - Заголовок
  - Опис вправи
  - Тривалість (опціонально)

**Приклади порад:**
```
1. "Нахили голови" - Повільно нахиліть голову вправо, затримайтесь на 5 секунд, потім вліво
2. "Обертання плечима" - Зробіть 10 обертань плечима вперед і 10 назад
3. "Скручування хребта" - Сидячи на кріслі, поверніть корпус вправо, потім вліво
4. "Правило 20-20-20" - Подивіться на об'єкт на відстані 20 футів впродовж 20 секунд
5. "Розтяжка шиї" - Покладіть руку на голову і акуратно нахиліть до плеча
```

#### 3.5.2. Логіка відображення порад
- **Випадковий вибір** поради з списку при кожній перерві
- Запобігання повторення останніх 5 показаних порад
- Можливість перегортання порад вручну (кнопки "Наступна порада" / "Попередня порада")
- Читабельний шрифт, достатній розмір тексту

#### 3.5.3. Управління порадами
- Можливість редагування списку порад через окремий файл
- Підтримка Unicode (кирилиця)
- Автоматичне оновлення списку при зміні файлу

## 4. Нефункціональні вимоги

### 4.1. Інтерфейс користувача
- **Простота:** мінімалістичний дизайн, зрозумілі елементи
- **Адаптивність:** коректне масштабування на різних дозволах екрану
- **Локалізація:** українська мова інтерфейсу
- **Кольорова схема:**
  - Робочий час: спокійні тони (зелений/синій)
  - Перерва: помаранчевий/жовтий
  - Повноекранний режим: темний фон для зменшення навантаження на очі

### 4.2. Продуктивність
- Мінімальне споживання ресурсів CPU (<1% в режимі очікування)
- Використання RAM: <50 MB
- Швидкий запуск програми (<2 секунди)

### 4.3. Надійність
- Збереження налаштувань при аварійному завершенні
- Автоматичне відновлення таймера при краху програми (опціонально)
- Логування помилок для налагодження

### 4.4. Безпека
- Всі дані зберігаються локально
- Відсутність підключень до інтернету
- Безпечне блокування екрану (можливість аварійного виходу)

### 5.2. Основні компоненти

#### 5.2.1. Timer (core/timer.py)
- Клас для управління таймером
- Методи: start(), pause(), reset(), tick()
- Події: on_work_end, on_break_end

#### 5.2.2. SoundManager (core/sound_manager.py)
- Відтворення звуків
- Управління гучністю
- Завантаження/вибір мелодій

#### 5.2.3. TipsManager (core/tips_manager.py)
- Завантаження порад з файлу
- Випадковий вибір без повторень
- Навігація між порадами

#### 5.2.4. MainWindow (ui/main_window.py)
- Головний інтерфейс
- Відображення таймера
- Кнопки керування

#### 5.2.5. BreakWindow (ui/break_window.py)
- Повноекранне вікно
- Відображення поради + таймера
- Блокування взаємодії

#### 5.2.6. SettingsWindow (ui/settings_window.py)
- Налаштування часу
- Налаштування звуку
- Автозапуск

## 10. Висновок

Даний TomatoTimer буде ефективним інструментом для підвищення продуктивності з акцентом на здоров'я користувача. Використання Python з Tkinter дозволить швидко створити кросплатформений додаток з необхідним функціоналом, а система блокування екрану забезпечить виконання перерв.

**Очікуваний час розробки MVP:** 2-3 тижні
**Повна версія зі всіма функціями:** 4-6 тижнів
